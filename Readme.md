# InboxIQ

> Privacy-first inbox intelligence for a cleaner, more focused digital life.

InboxIQ is a SaaS application that helps users understand and clean their email inboxes.

The platform identifies unwanted email subscriptions, provides inbox analytics, and helps users take control of their email attention.

## 🚧 Project Status

Currently under active development.

This project is also being built as a hands-on full-stack learning project.

## 🎯 Goals

- Detect unwanted email subscriptions
- Identify high-volume senders
- Analyze inbox clutter
- Help users unsubscribe from unwanted emails
- Provide useful inbox analytics
- Build a privacy-first architecture
- Eventually provide intelligent cleanup recommendations
